YouTube rank check

Find where a video ranks in YouTube search for a keyword, in a given country. No account, no key.

How this works

The check runs a signed-out YouTube search for your keyword from the country you pick and looks through roughly the top 100 results, videos and Shorts together. If your video is among them you get its position; if not, it is beyond the results checked. Signed-out results are not personalised, so they can differ from what you see when logged in. Results are cached briefly on the server, so checking the same video and keyword again within a short time returns the same answer.

Please keep it to a few checks a minute. The full YouTube rank tracker on crestlinesocial.com runs the same check. There is also a small command-line version in the GitHub repository.
